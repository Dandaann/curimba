# Curimba Produções

Site institucional da **Curimba Produções** — Produtora preta focada em cultura afro-brasileira: produção executiva, festivais, shows, estúdio e oficinas.

## Desenvolvimento Local

Requisitos: **Node.js LTS** ou **Bun**.

```sh
git clone https://github.com/Dandaann/curimba.git
cd curimba
bun install
bun run dev
```

O servidor local ficará disponível em `http://localhost:8080/`.
